# Sabt Retail — downloads

Installers and the auto-update feed for **Sabt Retail**, the offline Windows POS for kiryana and general stores.

Download the latest `Sabt.Retail-Setup-<version>.exe` from [Releases](https://github.com/aliamjad2099/sabt-retail-releases/releases).

Windows 10/11, 64-bit. The source code is private; this repository only hosts release files.
